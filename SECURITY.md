# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **SpatialForge AI**, please report it directly by opening an advisory or emailing the maintainer:

* Maintainer: Frank Asante-Van Laarhoven
* Repository: https://github.com/FrankAsanteVanLaarhoven/SpatialForge-AI

Please do not open public issues for sensitive security vulnerabilities. We will respond promptly and provide updates as fixes are deployed.
